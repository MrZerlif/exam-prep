## Билет 1. Формула полной вероятности. Формула Байеса. Пример применения.
*Источник: Лекция 3 — покрыт полностью.*

**План устного ответа:**
1. Дать определение полной группы гипотез: события H1,…,Hn попарно несовместны, и их вероятности в сумме дают 1.
2. Сформулировать и вывести (на словах) формулу полной вероятности.
3. Сформулировать формулу Байеса как «переворачивание» условной вероятности после того, как событие A уже наступило.
4. Разобрать пример на числах (см. флажок ниже).

**Формулы:**
- Полная группа гипотез: H1 + H2 + … + Hn, ΣP(Hi) = 1, Hi попарно несовместны.
- Формула полной вероятности: **P(A) = Σᵢ P(Hi)·P(A|Hi)**, сумма по i = 1..n.
- Формула Байеса: **P(Hk|A) = P(Hk)·P(A|Hk) / P(A)**, где P(A) считается по формуле выше.

**Пример из лекции:** три урны разного состава шаров.
⚠️ **Пробел в материале:** в извлечённом тексте лекции сохранилась только сама постановка («три урны разного состава»), но не конкретные числа (сколько шаров какого цвета в каждой урне) и не итоговый расчёт. Для устного экзамена нужен готовый числовой пример — возьмите его из своей тетради/учебника или придумайте свой (например: урна 1 — 2 белых и 3 чёрных, урна 2 — 4 белых и 1 чёрный, урна 3 — 1 белый и 4 чёрных; урна выбирается случайно, найти P(белый шар) и P(урна 2 | вынут белый)). Это единственное место, требующее досчитать вручную.

**Самопроверка:** Сможете ли вы с ходу объяснить, почему в знаменателе формулы Байеса стоит именно P(A), а не что-то ещё? Сможете ли вывести формулу Байеса из определения условной вероятности P(Hk|A) = P(Hk∩A)/P(A)?

## Билет 2. Распределение Пуассона: определение, параметры, мат. ожидание и дисперсия. Связь с биномиальным распределением.
*Источник: Лекция 4 — покрыт полностью.*

**План устного ответа:**
1. Дать формулу распределения Пуассона и назвать параметр λ.
2. Сказать, что λ — одновременно мат. ожидание и дисперсия.
3. Объяснить связь с биномиальным распределением как предельный переход (закон редких событий).
4. Привести пример.

**Формулы:**
- **P(X = k) = (λᵏ · e^(−λ)) / k!**, k = 0, 1, 2, …
- Связь с биномиальным: Bin(n, p) → Poisson(λ) при n → ∞, p → 0, так что n·p = λ = const.
- **M(X) = λ**, **D(X) = λ**.

**Пример из лекции:** число вызовов в call-центре за минуту.

**Самопроверка:** Почему при связи с биномиальным распределением важно, чтобы именно np оставалось константой, а не n или p по отдельности? Сможете объяснить своими словами, что значит «редкое событие» в этом контексте?

## Билет 3. Центральная предельная теорема: формулировка и условия применимости (без доказательства).
*Источник: Лекция 5 — покрыт полностью (доказательство отдельно не требуется — так и в билете, и в конспекте).*

**План устного ответа:**
1. Сформулировать содержательную идею: сумма большого числа независимых одинаково распределённых случайных величин с конечной дисперсией ведёт себя приближённо как нормальная случайная величина.
2. Дать формулировку теоремы Ляпунова (без доказательства) и условия применимости.
3. Подчеркнуть: доказательство не входит в программу — на экзамене доказывать не нужно, только точная формулировка и условия.

**Ключевые моменты:**
- Условия: X1, …, Xn — независимые случайные величины с конечной дисперсией.
- Утверждение: нормированная сумма (сумма минус её мат. ожидание, делённая на её стандартное отклонение) при n → ∞ сходится по распределению к стандартному нормальному закону N(0,1).
- Условие Ляпунова обеспечивает, что ни одно слагаемое не «доминирует» над суммой (вклад каждого отдельного X_i становится пренебрежимо мал на фоне всей суммы).

**Самопроверка:** Чем формулировка теоремы Ляпунова отличается от классической теоремы Линдеберга–Леви (для одинаково распределённых величин)? Проверьте это по своему учебнику/конспекту — в извлечённом тексте лекции точная формула условия Ляпунова не сохранилась, только словесное описание.

## Билет 4. Закон больших чисел в форме Чебышева: формулировка и доказательство через неравенство Чебышева.
*Источник: Лекция 6 — покрыт полностью, включая доказательство.*

**План устного ответа:**
1. Сформулировать теорему: X1,…,Xn независимы, одинаковое мат. ожидание μ, ограниченные дисперсии ⟹ среднее арифметическое сходится по вероятности к μ.
2. Привести неравенство Чебышева.
3. Провести полное доказательство (оно было показано на лекции целиком — ожидайте, что спросят именно вывод).

**Формулы и доказательство:**
- Неравенство Чебышева: **P(|X − M(X)| ≥ ε) ≤ D(X) / ε²**.
- Пусть X̄ₙ = (X1+…+Xn)/n. Тогда M(X̄ₙ) = μ, а D(X̄ₙ) = (1/n²)·Σ D(Xi) ≤ (1/n²)·n·C = C/n (где C — общая верхняя граница дисперсий).
- Применяем неравенство Чебышева к X̄ₙ: **P(|X̄ₙ − μ| ≥ ε) ≤ D(X̄ₙ)/ε² ≤ C/(n·ε²) → 0 при n → ∞.**
- Это и есть сходимость по вероятности X̄ₙ → μ.

**Самопроверка:** Сможете доказать это «с закрытыми глазами», не подглядывая, — особенно шаг с D(X̄ₙ) = (1/n²)ΣD(Xi) (используется независимость слагаемых)?

## Билет 5. Независимость случайных величин: определение через совместное распределение, критерий независимости, пример двух зависимых величин с нулевой ковариацией.

🚩 **ВАЖНО: этой темы нет в присланном конспекте лекций.** Конспект обрывается на лекции 6 (закон больших чисел), а билет 5 явно требует отдельную тему «независимость случайных величин», которую лектор, видимо, читал на другой лекции (не вошедшей в выгруженный текст) или планирует читать позже. Карточка ниже составлена по стандартному материалу курса теории вероятностей общего профиля — **это не пересказ вашего лектора, а типовое содержание**, которое обычно спрашивают под такой формулировкой. Обязательно сверьте с тем, как это определение и пример давал именно ваш лектор Иванов А.П. — могут отличаться обозначения, порядок изложения или выбранный контрпример.

**План устного ответа (типовой):**
1. Дать определение независимости через совместное распределение.
2. Сформулировать критерий независимости (факторизация плотности/функции вероятности).
3. Сказать, что независимость влечёт некоррелированность (Cov = 0), но не наоборот, и привести контрпример.

**Формулы (стандартные, проверьте по своим источникам):**
- Определение: X и Y независимы ⟺ F(x,y) = F_X(x)·F_Y(y) для всех x, y (F — совместная функция распределения).
- Критерий для дискретных величин: P(X=x, Y=y) = P(X=x)·P(Y=y) для всех x, y.
- Критерий для непрерывных величин: f(x,y) = f_X(x)·f_Y(y) (плотности).
- Независимость ⟹ Cov(X,Y) = 0, но обратное неверно.

**Пример зависимых, но некоррелированных величин (типовой):**
Пусть X распределена симметрично относительно нуля (например, равномерно на [−1, 1]), и Y = X².
- Cov(X,Y) = M(XY) − M(X)M(Y) = M(X³) − M(X)·M(X²) = 0 − 0 = 0 (оба слагаемых равны нулю из-за симметрии распределения X).
- При этом Y полностью определяется значением X (Y — детерминированная функция X), то есть величины явно зависимы.
- Вывод: нулевая ковариация не гарантирует независимость.

**Самопроверка:** сможете доказать, что M(X) = 0 и M(X³) = 0 для X, равномерно распределённой на [−1, 1], не считая интеграл заново каждый раз?
