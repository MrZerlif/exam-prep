# Заметки об неопределённостях

- **Билет 5 (независимость случайных величин)** отсутствует в предоставленном конспекте лекций (тот охватывает только лекции 3–6, что соответствует билетам 1–4). Карточка для билета 5 составлена по общему стандартному материалу курса теории вероятностей (определение через совместное распределение, критерий факторизации плотности, контрпример X ~ Uniform(−1,1) и Y = X² для «зависимые, но некоррелированные»), а не из материалов конкретного лектора. Это явно помечено в самой карточке и в ответе учащемуся, с рекомендацией сверить с лектором/учебником.
- **Билет 1, пример с тремя урнами** — в конспекте есть только упоминание примера («разобран пример с тремя урнами разного состава шаров»), конкретные числа не сохранились (вероятно, из-за OCR или потому что пример был на слайде-рисунке). В карточке предложен собственный числовой пример-заготовка для тренировки, с пометкой, что лучше подставить оригинальный пример учащегося.
- **Билет 3, условие Ляпунова** — конспект даёт только словесное описание сути условия (доказательство не входит в программу), точная формула условия Ляпунова (с моментами третьего порядка) не приведена в тексте лекции. В карточке дано только содержательное описание, с пометкой сверить точную формулу по учебнику.
